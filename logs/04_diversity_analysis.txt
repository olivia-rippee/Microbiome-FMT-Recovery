PHASE 4 CONCLUSION
============================================================

Alpha and beta diversity metrics were calculated across
the four longitudinal FMT samples.

All downstream diversity metrics were calculated using the
same feature table rarefied to 15,000 reads per sample.

Alpha diversity included observed features, Shannon
diversity, and Faith's phylogenetic diversity.

Beta diversity included Bray-Curtis, Jaccard, weighted
UniFrac, and unweighted UniFrac distances.

PCoA and Emperor visualizations were generated for each
beta-diversity metric.

A rarefaction depth of 15,000 reads was selected so that
all four samples were retained in the pilot analysis.

Because only one participant is included, diversity
patterns are interpreted descriptively rather than as
population-level statistical inference.
